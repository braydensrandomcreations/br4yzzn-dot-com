# Web Ports

A plain-HTML starter site with a dark-blue-to-light-blue gradient and default browser buttons.

- `index.html` — landing page with a button to the ports page.
- `ports.html` — placeholder port list with thumbnails in `thumbs/`.

Replace the placeholder entries, thumbnail files, and `#` links with your own ports.

No build step. Open `index.html` in a browser.

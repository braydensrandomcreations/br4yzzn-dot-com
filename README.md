# Web Ports

A plain-HTML starter site with a dark-blue-to-light-blue gradient and default browser buttons. The layout is loosely inspired by boolonx.com, using Inter, centered text, and a soft fade-up animation.

- `index.html` — landing page with a button to the ports page.
- `ports.html` — empty ports page with a centered subtitle and a back button.

No build step. Open `index.html` in a browser.
